# 🏍️ Motorcycle Sales Management System

A web-based motorcycle sales application built using Java Servlet/JSP and the MVC architecture. This project demonstrates backend development skills, database integration, session management, and teamwork experience.

---

## 🚀 Features

* **User Authentication:** User registration and login workflows with server-side validation and secure session handling.
* **Product Catalog:** Dynamic motorcycle listing with filtering capabilities and detailed product specification pages.
* **Shopping Cart:** Full-featured session-based shopping cart supporting add, remove, and update operations with automatic total price calculation.
* **Database Integration:** Reliable data persistence optimized via standard JDBC techniques for stable data operations.
* **UI-Backend Consistency:** Seamless integration between dynamic JSP content and backend business logic.

---

## 🛠️ Tech Stack

* **Backend:** Java, Servlet, JSP, JDBC
* **Frontend:** HTML5, CSS3, JavaScript, Bootstrap
* **Database:** MySQL
* **Architecture:** MVC (Model-View-Controller)
* **Server:** Apache Tomcat
* **Tools:** IntelliJ IDEA, Git, GitHub

---

## 📁 Project Structure

```text
src/
 ├── controller/     # Servlet controllers for request handling & routing
 ├── dao/            # Data Access Object layer for JDBC queries
 ├── model/          # Business logic and entity classes
 └── utils/          # Database connection helpers

web/
 ├── css/            # UI Stylesheets & Bootstrap
 ├── js/             # Client-side scripts & input validation
 └── (JSP files)     # Dynamic view pages
```

## ⚙️ Installation & Setup

### 1. Clone the repository
```bash
git clone https://github.com/giapcb/Website_Ban_Xe_May.git
```

### 2. Configure Database
* Create a database in your local **MySQL** environment.
* Import your project's SQL schema file into the newly created database.
* Update your database credentials (username and password) inside the database helper class in `src/`.

### 3. Run the Application
* Open the project folder using **IntelliJ IDEA** or **NetBeans**.
* Configure your local **Apache Tomcat** application server.
* Build and deploy the application onto the server to test locally.
